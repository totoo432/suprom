📱 Hướng dẫn dùng trên iPhone / iPad
Bước 1 — Tải file về iPhone
Trong Claude.ai → nhấn vào file epub-tts-reader.html → nhấn nút tải xuống ↓ → file lưu vào Tệp > Tải về
Bước 2 — Mở bằng Safari
App Tệp không có nút "Mở trong Safari" trực tiếp.
Làm theo một trong hai cách sau:

Cách A (nhanh nhất):
Mở app Tệp → tìm file epub-tts-reader.html → nhấn giữ file → chọn "Chia sẻ" → kéo xuống tìm biểu tượng Safari → nhấn vào

Cách B (nếu không thấy Safari trong Chia sẻ):
Mở app Tệp → nhấn giữ file → chọn "Sao chép" → mở Safari → thanh địa chỉ gõ file:// → Safari sẽ hỏi vị trí, dán đường dẫn vào

Cách C (đơn giản nhất):
Mở Safari trước → nhấn vào thanh địa chỉ → nhấn biểu tượng 📎 hoặc chọn "Tệp" bên dưới bàn phím → duyệt đến file epub-tts-reader.html → nhấn mở

⚠️ Không dùng Chrome trên iOS — Chrome không có giọng Siri tiếng Việt
Bước 3 — Bật giọng tiếng Việt cho Siri
Nếu dropdown "Giọng đọc" không có tiếng Việt:
Cài đặt → Trợ năng → Nội dung đọc → Giọng nói → Tiếng Việt → tải giọng về
Hoặc: Cài đặt → Siri & Tìm kiếm → Ngôn ngữ → Tiếng Việt
Bước 4 — Lần đầu mở trang
Safari cần 1 lần chạm để kích hoạt giọng nói.
Chỉ cần nhấn vào bất kỳ đâu trên trang → dropdown sẽ tự điền giọng Siri tiếng Việt.
